The order is:part1.midpart2.midpart3.midpart4.midpart5.midpart6.mid...etcDISCLAIMER: The chunks won't work with some sequencers. As soon as the Virus is receiving an OS dump, it doesn't accept any other data. It will terminate OS update, if other data (such as a reset message for instance) appear. Some sequencers send reset messages, as soon as a song is being loaded.So why using the this version at all? The Virus OS is rather big for a MIDI file and some older sequencers are not capable of dealing with such an amount of data. Their RAM is simply too small. Uploading the OS in chunks overcomes this limitation.Copyright 2001 Access Music Electronics GmbH
